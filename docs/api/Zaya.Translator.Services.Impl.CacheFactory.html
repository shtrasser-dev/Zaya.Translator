Class CacheFactory

Factory that conditionally wraps an ITranslatorSession with a CachingTranslatorSession based on engine settings. Translators call TryWrap(ITranslatorSession, SettingDescriptorList) in their CreateSessionAsync to add caching transparently when enabled by the user.
