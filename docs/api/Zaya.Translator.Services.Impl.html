Namespace Zaya.Translator.Services.Impl

Classes

CacheFactory

Factory that conditionally wraps an ITranslatorSession with a CachingTranslatorSession based on engine settings. Translators call TryWrap(ITranslatorSession, SettingDescriptorList) in their CreateSessionAsync to add caching transparently when enabled by the user.

CacheSettingDescriptors

Provides the SettingDescriptor list for cache configuration. Translators include All in their own BuildSettings() return value so that the cache settings are rendered and read together with the translator's own settings.

CacheSettingsKeys

Machine-readable keys for translation cache settings. These keys are passed as part of the engine settings dictionary and consumed by TryWrap(ITranslatorSession, SettingDescriptorList).

CachingTranslatorSession

Decorator over ITranslatorSession that caches translation results using an ITranslationCache instance. Both single-text and batch TranslateAsync calls are intercepted: cached texts are returned immediately, and only uncached texts are forwarded to the inner session.
